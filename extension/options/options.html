Character Chatbot

Apna character set karo, backend connect karo, aur chats mein AI se reply banwao. Auto-send tabhi hota hai jab tum us chat mein khud ON karo.

1 Apni AI key se connect karo (code ki zaroorat nahi)

Apni free Groq API key daalo (Groq = inference company, console.groq.com/keys; xAI ka Grok nahi). Key sirf is computer ke Chrome mein save hoti hai (sync nahi hoti) aur AI requests seedha provider ko jaati hain - koi server beech mein nahi. Key kisi chat ya dusre ko mat bhejo.

Test mein ek chhota sa asli AI call hota hai (tumhari apni key ka thoda usage).

1b Ya hosted backend se connect karo (pairing code)

Pairing code ek hi baar paste karna hai (30 minute mein expire hota hai). Hosted server so raha ho to pehli baar 1 minute tak lag sakta hai.

3 Advanced: backend URL / token

Privacy: character settings Chrome sync mein tumhare apne Google account ke through sync hoti hain. Auth token secret hai - wo kabhi sync nahi hota, sirf isi device par rehta hai. Chat messages sirf tab backend/AI ko jaate hain jab tum us chat mein AI on karte ho.

Preview (dummy test)

Ek sample incoming message likho aur dekho current settings ke saath AI kya reply karta. Ye ek REAL API call hai dummy message par - kisi asli chat par kuch nahi jaata.

Form auto-fill details (asli facts, review-first)

Ye details right-click > "Form auto-fill" par web forms mein bharti hain. Sirf jo bharoge wahi use hoga; kuch invent nahi hota. Password/OTP/card/ID fields kabhi auto-fill nahi hote, aur Submit hamesha tum khud dabate ho. Ye CHARACTER ka fictional data nahi hai - forms ke liye asli details.

Emergency stop

Stop all = sab chats mein AI turant band, queued/in-flight reply bhi cancel. Resume sirf tum kisi chat mein dobara on karoge tab.
